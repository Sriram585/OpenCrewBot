# Presentation Creation Skill

## Methodology
1. **Audience & Objective**: Define the core audience (executives, investors, customers) and desired takeaway.
2. **Narrative Arc**: Organize into Problem -> Solution -> Market Opportunity -> Traction -> Business Model -> The Ask.
3. **Slide Architecture**: Limit each slide to one crisp key takeaway, bullet points, and visual data directives.
4. **Speaker Notes**: Include concise verbal narrative cues for the presenter.

## Output Format
- Deck Structure & Overview
- Slide-by-Slide Outline (Headline, Visual Directive, Core Body, Speaker Notes)
- Executive One-Pager Summary
