# Lead Generation Skill

## Methodology
1. **Ideal Customer Profile (ICP)**: Define firmographics (headcount, revenue, tech stack, industry) and target titles.
2. **Account Discovery**: Search and verify qualified companies exhibiting active buying signals.
3. **Decision Maker Mapping**: Identify relevant executives (VPs, Directors, C-level) matching ICP criteria.
4. **Value Angle Formulation**: Pinpoint customized pain points and initial outreach hooks for each prospect.

## Output Format
- ICP Definition Summary
- Target Account List (Company, Size, Industry, Reason for Fit)
- Key Prospect Profiles (Title, Focus Area, Tailored Value Hook)
- Recommended Next Step
