# Financial Modelling Skill

## Methodology
1. **State Assumptions**: Clearly outline unit economics, pricing, churn rates, gross margins, and CAC.
2. **Model Growth Scenarios**: Construct conservative, base, and aggressive revenue curves.
3. **Cost Structure**: Detail fixed operating expenditures and variable cost of goods sold.
4. **Cash Flow & Breakeven**: Calculate runway, burn multiple, and month-of-breakeven.
5. **Arithmetic Validation**: Use programmatic calculations (via code or deterministic math tools) to ensure 0 rounding errors.

## Output Format
- Summary Metrics (ARR, Gross Margin, Burn Rate, Runway)
- 12-Month Financial Projections Table
- Sensitivity Analysis
- Key Risks & Hedging Strategy
