# Competitor Analysis Skill

## Methodology
1. **Identify Rivals**: Map direct, indirect, and emerging alternative competitors.
2. **Feature & Capability Matrix**: Compare feature parity, technical architecture, and usability strengths.
3. **Pricing & Packaging**: Document tiers, billing models, and value metrics.
4. **SWOT Assessment**: Formulate detailed Strengths, Weaknesses, Opportunities, and Threats for each competitor.
5. **Differentiators**: Identify gaps where our offering can achieve decisive differentiation.

## Output Format
- Competitor Overview Table
- Detailed Feature Comparison Matrix
- Pricing Tier Analysis
- Comprehensive SWOT Breakdown
- Strategic Differentiation Playbook
