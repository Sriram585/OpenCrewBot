# Data Analysis Skill

## Methodology
1. **Data Ingestion**: Parse input dataset (CSV, JSON, database tables) and validate column schemas and nulls.
2. **Descriptive Statistics**: Compute totals, medians, averages, distributions, and variance.
3. **Segmentation**: Group by cohort, category, geography, or time interval to uncover hidden variance.
4. **Funnel & Conversion**: Measure step-by-step conversion rates and locate highest-leverage bottleneck drop-offs.
5. **Chart Data Preparation**: Output structured, chart-ready datasets for dashboard visualization.

## Output Format
- Executive Metrics Summary Table
- Cohort / Segmentation Breakdown
- Funnel Drop-off Analysis
- Strategic Business Recommendations
